Trade-offs / failure handling

Useful systems stay understandable when the happy path breaks.

Decision
Keep Telegram as the low-friction interface and SQLite as durable local state.
Failure path
Use readable fallback messages, preserve user state and make backup/recovery behavior explicit.
Security
Never expose tokens in static files; keep external endpoints optional and server-configured.
Lesson
Ship one complete workflow first, then expand only when real usage reveals the next constraint.
